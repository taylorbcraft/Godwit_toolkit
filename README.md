# Godwit Movement Explorer

Godwit Movement Explorer is an interactive application for exploring Black-tailed Godwit (*Limosa limosa limosa*) movements across the East Atlantic flyway. It combines tracking records with satellite-derived environmental layers to help users examine where and when godwits move and the conditions they encounter.

Application: <https://tbcraft.shinyapps.io/godwit-movement-explorer/>

Satellite Index Explorer: <https://ee-tbcraft.projects.earthengine.app/view/satellite-index-explorer>

## Features

- filter tracking locations by migration year, date, tagging site and geographic area
- view daily locations and complete movement tracks across the flyway
- select individual birds or focus on records within a chosen area
- create clipped S2REP, NDVI, EVI, NDWI, NDMI, SAVI and SWIR satellite layers
- compare uploaded satellite layers with daily bird locations
- review movement maps, selection summaries and encountered environmental values
