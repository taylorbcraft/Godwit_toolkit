# Legacy toolkit source

This directory contains source code for retired regional applications and Earth Engine utilities. The scripts are retained as implementation references and are not part of the active application or deployment workflow.

Associated rasters, movement extracts, spatial datasets and deployment metadata are not included. The archived applications therefore require their original external data to run.

The active application is located in `Flyway_Tracking_Summary_App/`. The maintained Earth Engine source is `GEE_code/Satellite Index Explorer.js`.
